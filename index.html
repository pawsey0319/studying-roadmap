第 1 周

多设备同步

进度和笔记会存进你 GitHub 账号下的一个私有 Gist。每台设备填一次同一个令牌就行。

  1. 打开 GitHub 新建细粒度令牌，名称随意，有效期建议选 1 年。
  2. Repository access 选 “Public repositories”，Account permissions 里只把 Gists 设为 “Read and write”，其他都不要开。
  3. 生成后复制以 github_pat_ 开头的令牌，粘贴到下面。

公用电脑或别人的电脑上不要设置同步。令牌只保存在这台设备的浏览器里，只会发给 api.github.com。设备丢失时去 GitHub 设置里删除这个令牌即可。
