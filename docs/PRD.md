# 学习路线与现场学习 Agent 产品需求

文档版本：1.1｜更新：2026-11-10｜状态：用户已确认方案，整体实现与统一验收中。本文补建于全局需求沉淀规则生效后；不把已开发代码等同验收完成。

## 1. Executive Summary

### 背景、原始诉求与目标
面向跨领域学习者：既需要理解阅读材料，也需要现场操作指导；赶任务时可选择授权直接完成，不被强制教学。任务完成不等于掌握。原有路线只能重规划、导航分散、语音与图片链路不完整，学习过程难回顾，个人偏好与开发者质量反馈混在一起。

统一方案：网页学习工具台 + 可理解/指导/授权执行的学习 Agent；双路径按住说话；Android 外部页面咨询；可回顾会话和独立质量分享；开发者据评测审核升级。用户明确要求按完整方案连续执行后统一验收，不逐阶段要求其自行选配 ASR。

### 成功标准（验收目标而非实测）
- 语音两模式请求协议100%分离；取消、超时、撤权均不迟到发送，不把转写冒作直接音频理解。
- 来源画面未经系统授权、逐帧确认、明确目的地许可或已超过30秒时，100%阻止发送。
- 会话可回顾、续接不重放执行、删除不被生成中请求回填；质量上报无隐式附件。
- 至少240例音频/视觉项目固定评测作为模型生产选择依据；小规模smoke不能宣称合格。
- 无开发者审核与可信行为评测时不能批准生产发布；候选生成不持有生产权限。

## 2. User Experience & Functionality

### 人物与用户故事
- 学习者：希望保留现有路线只增删阶段；桌面工具统一入口、手机设置默认折叠、搜索不误弹键盘。
- 现场学习者：希望在同一会话理解材料、获取操作指导或授权执行；模式由自己决定。
- 手机阅读者：希望在微信/浏览器点击咨询后授权来源，Agent在本机等待问题，不每帧上云。
- 管理者：希望只接收用户明确分享的材料，并据可信评测审核候选改进。

### 功能与验收规则
**LH-001**：公共方向阶段隐藏/恢复，自有方向增删，默认不重做已有路线；工作台容纳笔记等，保留我的/搜索/公共区域并行；规划弹窗初始简洁、锁背景滚动；手机搜索无自动键盘、设置折叠。

**LH-002**：同一任务可在理解/指导/执行间切换；直接完成不绕过高风险确认。文件权限不等于执行权限；续接重新校验来源环境与授权。PC完整伴侣不因Android实现而宣称完成。

**LH-003**：语音按钮启用时按住录音、松开发原音频给真音频模型，关闭时松开仅转文字草稿，用户主动发送。按下锁定本次模式，取消不发送，失败不能静默降级。直接音频前端须保留结束信息：明确非stop或拒绝时提示错误，不将残余回答作为成功消息保存；旧服务缺失原因可兼容，但必须标为未知，SSE的[DONE]不等于自然stop。回复语言规则在直接音频中并入同一条user文字提示并计入完整字符预算，不能额外插system破坏单消息服务契约；普通聊天不变。默认文字答复，可选朗读；语音原声默认不长期保存。录音60秒/10MiB、处理超时明确提示。实现预算说明（LH-003/005，2026-11-10）：模型可声明更严格的输出 token、文字上下文字符数和音频秒数预算；UI 明示限制，录音处理前先检查时长，超限拒绝并提示缩短录音/使用较少上下文，不静默裁剪材料或改走转写。

**LH-004**：咨询入口说明Android系统共享权限；授权会话内来源不可见时本机限频更新最近画面，咨询自身可见时冻结以免递归；过期画面不当实时。用户核对来源后再确认发送目的地。停止/撤权/锁屏/系统终止释放资源；来源包名/域名无法可靠获取时显示未知，不猜测。Android14单App选择由系统与用户控制；旧版整屏限制醒目说明。不保证微信所有受保护页可采集。

**LH-005**：开发者负责服务配置，不要求普通用户研究ASR。本机视觉除了离线评测，还须提供实际鉴权/CORS图片咨询服务并走浏览器联调；与ASR共用进程级加载互斥，避免16GB设备并发加载。先复用可验证资源，免费本地小模型优先，不擅自调用收费推理。ASR、直接音频理解、视觉理解分别评测，不拿字错率当问答准确率。参数名不等于总内存；M2 16GB串行加载模型。合成样例、公开数据、真实设备分开记录。实现预算说明：开发者预设可选 audio.maxTokens/contextChars/maxSeconds，均为有合理上限的正整数，分别映射 audioMaxTokens/audioContextChars/audioMaxSeconds；旧预设兼容，通用模型默认输出2048不变。当前 Ultravox 本机安全预算为上下文窗口1024 token、输出128 token、文字上下文256字符、音频30秒；这是部署预算而非模型能力验收，不标 verified。显式请求超预算必须拒绝，不降低请求或截断内容。

**LH-006**：保存任务摘要、事件、证据定位与检查点，不默认保存原音频/录屏。个人学习反馈只影响个人，不自动进入管理者收件箱。质量反馈逐项选内容、独立预览、明确同意、可撤回；后台每次验证账号/所有权/管理员权限。认证刷新也须绑定账号代际：退出、换号或后端配置变化后，旧刷新成功不得复活旧账号，旧刷新失败不得清掉新账号；等待令牌的请求不得跨账号继续发送。

**LH-007**：已脱敏授权反馈→隔离候选建议→固定集结构/行为评测→人工审核→灰度→回滚。仅模型自评或结构检查不得标行为通过。模型明确报告length/content_filter/tool_calls等非自然结束或拒绝回答时，不将可解析的残余JSON当作完整候选；兼容旧接口缺失结束原因，但不得据此宣称自然结束。运行器可被开发者CI定时调用，但本次不替用户创建机器定时任务、不自动生产发布。

### 非目标
不开放用户任意自定义Agent；不默认全桌面持续上传；不承诺任意App自动点击；不默认保存原媒体；不在缺设备/权重/后台部署时将mock当真实验收。

## 3. AI System Requirements
- 工具：ASR转写服务、真实input_audio理解适配、图片视觉推理、可取消语音状态机、Android MediaProjection、只读材料检索、受控执行策略。
- 模型路由：结构正文优先，截图补充；小模型不合格升级而非强行省资源；直接音频不走ASR冒充。
- 评测：报告精确模型revision、样本hash、许可、硬件、延迟/内存、字错率/事实引用/拒绝与权限行为；mock仅验证协议。LH-005证据修正：视觉与直接音频服务均透传运行库的实际结束原因与token计数；音频HTTP适配器不得只提取正文后由网关硬编码stop。未知原因记录null，不硬编码stop，也不由输出计数推断length；历史批次不回填不存在的元数据。评分保留逐字段诊断，但明确非stop结束的响应不得单例通过；缺失原因仅表示未知，不能从正确字段或token计数推断自然结束。质量门槛与实际通过分别列。
- LH-003/004/006并发安全补充（2026-11-10）：提交准备阶段（配置、额度、屏幕授权等异步等待）必须绑定当前抽屉打开代际及会话实例；期间关闭/切换话题使未发请求取消，不清空新会话的草稿或附件。已经开始生成的其他话题仍可后台完成，保持原有多话题体验。来源预览与授权操作同样不得在停止或切换后迟到显示敏感画面。
- LH-005开发实验补充（2026-11-10）：视觉v1严格失败后允许独立prompt v2实验，用无参考答案的逐字段空结构明确输出契约、原样Unicode和缺失null；保留原图/原manifest/原评分器与v1结果，逐次记录提示版本/hash。v2属于同一开发集上调参，不能当独立冻结集或生产通过。

## 4. Technical Specifications
- 原生ESM网页、IndexedDB本地会话；Android Capacitor窄IPC + 私有前台采集服务；模型可运行在电脑服务，不强制手机本地。
- LH-003/005集成验收：除单层mock，须以真实本机HTTP网关与实际前端provider验证stop/未知/截断/拒绝、鉴权及不走ASR；模型后端为替身时明确标为协议证据，不能计入模型质量通过。英文完整提示预算须验证等于边界可发送、超出1字符发送前拒绝；测试临时文件独立隔离，启动失败也回收服务，不覆盖项目文件。
- 语音独立配置与能力发现，不继承平台凭据；本地服务限制Origin、token、大小、时长及并发，不接受任意远程媒体URL。
- 质量后台复用现有CloudBase用户认证/RPC；独立增量SQL、默认关闭，管理员只能服务端授予；候选状态不等于真实部署。
- LH-005实验进程生命周期：音频实验正常退出、启动异常、内存保护或终止信号均需回收内部推理子进程；超时须强制终止并wait。可用真实轻量子进程验证清理机制，但不代替模型资源/质量实测；child RSS只记采样时刻，不冒峰值。
- 安全：不记录密钥，不把屏幕/项目材料当指令；凭据与生产权限隔离，原媒体内存处理；撤权与删除覆盖晚到异步结果。

## 5. Risks & Roadmap
- 顺序：双语音→Android阅读→最小合格模型评测→会话/双反馈/审核；现按用户要求并行实现、统一联调验收。
- 风险：本机原无Android SDK的障碍已用隔离JDK21/SDK36解决；仍无真机授权/网络联调证据。公共权重下载/依赖网络失败，模型准确性未知，系统受保护页面不可采；云RPC未部署。需逐项提供真实证据，不能以代码测试替代。
- 实施边界：不自动pull/rebase/commit，不擅付费、不擅生产部署；真正设备授权、付费或凭据事项最终集中说明。
- 关联设计：`docs/superpowers/specs/2026-11-10-learning-agent-design.md`、`2026-11-10-learning-agent-implementation-plan.md`、`2026-11-10-audio-vision-model-research.md`。

### DeepSeek API 图片接入补充（2026-11-10，LH-004/005）
用户确认继续使用既有DeepSeek，并要求连续完整验证，不逐步停下来询问。文字与视觉采用官方支持图片输入的 `deepseek-flash`；复用CloudBase认证/额度/退款逻辑，服务端须显式声明视觉能力后前端才允许平台截图。仅支持user消息中的受限内联PNG/JPEG/WebP/GIF及text块，拒绝未知块、音频和远程图片URL，限制图片数/总字节与正文长度，不静默丢弃。旧纯文本与Anthropic路径保持兼容，未配置视觉模型的旧部署继续明确拒绝图片。保留原始屏幕逐帧授权与不落盘策略。真实API成功与本地协议测试分别记录；现有1元测试预算不自动扩大，不擅生产发布。Android由用户安装后自行测试，不要求ADB。

### PC设置加载可靠性修正（2026-11-11，LH-001/005）
用户反馈PC设置页持续显示加载骨架。设置页不得等待云端平台额度或模型能力请求才显示；本地外观、备份、账号等控件先可用，平台信息独立有界加载、明确错误与重试。旧页面、切换账号或重复请求的迟到结果不得覆盖当前状态。已有模型选择在能力加载失败时保持原值，不清空用户配置。验收须模拟已登录平台用户的请求永久pending，而不仅核验HTTP200或无登录环境。
